# Hagiographies Local Map

Static MapLibre GL JS map for browsing hagiographic data geographically. Served by Caddy
through the project gateway (port 9160); also openable as a plain static page during
development.

## How it works

- `index.html` renders the map and reads `data/hagiographies_map.geojson` (the points,
  generated by `just export-map`).
- The basemap is a [Protomaps](https://protomaps.com) PMTiles archive, styled with
  `@protomaps/basemaps`. Two basemaps are supported:
  - `data/world.pmtiles` — the built basemap, produced/refreshed by `just map-data`
    (or `node scripts/download-world-pmtiles.js`). Gitignored (derived artifact).
  - `data/world-fallback.pmtiles` — a committed basemap (from the GhentCDH Pihka project)
    shown automatically when `world.pmtiles` is absent, so a fresh checkout always renders
    a map.
- On load, `index.html` probes for `world.pmtiles`; if it is missing it falls back to
  `world-fallback.pmtiles`.

## Structure

- `index.html` — the map application (MapLibre + PMTiles + Protomaps basemap).
- `data/` — `hagiographies_map.geojson`, `world.pmtiles` (built), `world-fallback.pmtiles`
  (committed fallback).
- `scripts/download-world-pmtiles.js` — downloads/extracts a PMTiles basemap for a bbox.

## Maintenance

### Refresh the map data (points)
```sh
just export-map
```
Regenerates `data/hagiographies_map.geojson` from PostgreSQL.

### Rebuild the basemap
```sh
just map-data
```
Extracts a fresh `data/world.pmtiles` for the configured bounding box. To extract a
different area directly:
```sh
node scripts/download-world-pmtiles.js --bbox=W,S,E,N --output=world.pmtiles --maxzoom=8
```
(Requires the `pmtiles` CLI on the host, or run it via the `just map-data` Docker path.)
